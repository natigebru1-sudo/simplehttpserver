# Simple Express.js Static File Server

A lightweight static file server built with **Express.js**, **Node.js**, and ES Modules.

## Features

- Serves static assets and HTML files dynamically using Express middleware.
- Environment variable support via `dotenv` for custom port configuration.
- Automatic server restarts during development using `nodemon`.
- Modular route handling and centralized 404 error management.

## Prerequisites

Make sure you have **Node.js** and **npm** installed on your machine.
